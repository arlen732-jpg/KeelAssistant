# 彈出視窗（無 Designer 的程式碼建構 Form）

適用於 `AlarmForm`（響鈴通知）、`MusicForm`（WebView2 播放器）這類「不進 Windows Forms 設計器、純程式碼組控件」的彈出視窗。與一般 WinForm 專案常見的 `Form.Designer.cs` + `InitializeComponent()` 模式不同，本專案的彈出視窗全部手寫。

## 完整範本結構

```csharp
public sealed class XxxForm : Form
{
    public XxxForm(...)
    {
        Text = "🔔 標題";
        Width = 360;
        Height = 200;
        StartPosition = FormStartPosition.CenterScreen;
        AutoScaleMode = AutoScaleMode.Dpi;

        var iconPath = Path.Combine(AppContext.BaseDirectory, "assets", "app.ico");
        if (File.Exists(iconPath))
            Icon = new Icon(iconPath);

        var lblTitle = new Label { Text = "...", Dock = DockStyle.Top, Height = 70, ... };
        var btnStop = new Button { Text = "...", Dock = DockStyle.Bottom, Height = 50, ... };
        btnStop.Click += (_, _) => Close();

        // 控制項 Dock 由下往上疊：先加底部/後加的元件，再加上方元件
        Controls.Add(btnStop);
        Controls.Add(lblTitle);
    }
}
```

## 與通用寫法的差異

- **不呼叫 `InitializeComponent()`、沒有 `.Designer.cs`**：視窗屬性（`Text`/`Width`/`Height`/`StartPosition`）與控件直接在建構子內以物件初始設定式（object initializer）宣告，因為這些是輕量彈出視窗（通知、播放器），不值得維護 Designer 檔。
- **圖示統一手動載入 `assets/app.ico`**，因為未走 `InitializeComponent`，不會套用專案的 `ApplicationIcon`：
  ```csharp
  // [日期] - [作者] - 視窗圖示套用 assets\app.ico（原 InitializeComponent 未被呼叫，沿用 WinForms 預設圖示）- Start
  var iconPath = Path.Combine(AppContext.BaseDirectory, "assets", "app.ico");
  if (File.Exists(iconPath)) Icon = new Icon(iconPath);
  // - end
  ```
- **佈局固定用 `Dock`，不用絕對座標/`TableLayoutPanel`**：`Controls.Add` 的順序決定疊層順序，`Dock.Bottom`/`Dock.Top` 的元件要先加後加的會在外側——加入順序寫在註解裡提醒維護者（見 `AlarmForm`：先加 `btnStop`(Bottom) 再加 `lblTime`(Top) 再加 `lblTitle`(Top)）。
- **中文顯示固定用 `"Microsoft JhengHei UI"` 字型**，標題級文字用 `FontStyle.Bold` + 較大字級（14~16F），避免用系統預設字型。
- **關閉行為依視窗用途二選一**：
  - 一次性通知視窗（`AlarmForm`）：允許使用者關閉，`OnFormClosed` 觸發 callback 做清理：
    ```csharp
    protected override void OnFormClosed(FormClosedEventArgs e)
    {
        _onStop();
        base.OnFormClosed(e);
    }
    ```
  - 常駐可重複開啟的視窗（`MusicForm`）：攔截使用者關閉，改為隱藏＋停用內容，保留控制項實例供下次重用：
    ```csharp
    protected override void OnFormClosing(FormClosingEventArgs e)
    {
        if (e.CloseReason == CloseReason.UserClosing)
        {
            e.Cancel = true;
            StopAndHide();
            return;
        }
        base.OnFormClosing(e);
    }
    ```
  ⚠️ 注意：新增常駐型視窗時務必攔截 `CloseReason.UserClosing`，否則使用者按右上角 X 會直接 Dispose 掉 WebView2/控件，導致下次呼叫時整個重建、狀態遺失。
- **非同步初始化的元件（如 WebView2）用「就緒旗標 + 暫存值」模式**，避免呼叫端在初始化完成前操作導致例外：
  ```csharp
  private bool _ready;
  private string? _pendingUrl;
  // 呼叫時：if (_ready) 直接操作; else 暫存到 _pendingUrl，初始化完成後補做
  ```
